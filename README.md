# pyengines
Pyengines is a **Python library** for engines, It contains many engines to be used in simple Syntaxes.

You can **Install the Library** By using:

Command prompt:
* **CMD [Windows]**
* pip install pyengines
* python -m pip install pyengines

Pydroid:
* **Pydroid [Android]**
* Menu ➝ Pip ➝ Install ➝ pyengines & Install

Termux:
* **Termux [Android]**
* Termux ➝ pkg install python ➝ pip install pyengines (if python is not installed yet)
* Termux ➝ pkg install python ➝ python -m pip install pyengines (if python is not installed yet)
* Termux ➝ pip install pyengines (if python is installed)
* Termux ➝ python -m pip install pyengines (if python is installed)
